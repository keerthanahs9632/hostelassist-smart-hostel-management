# HOSTELASSIST — Smart Hostel Operations & Predictive Maintenance

HOSTELASSIST is a smart, full-stack predictive maintenance and facilities operations platform designed specifically for hostels. It streamlines complaint registrations, prioritizes issues with predictive SLA models, detects recurring failure patterns, and automates technician assignments.

## ✨ Features

- 🔄 **4-in-1 Dual User Interface:** One-click role-switching between **Student**, **Hostel Warden**, **Technician**, and **System Admin** dashboards.
- 📱 **QR Asset Tag Generator:** Instantly generate printable QR asset tracking cards for hostel hardware (e.g., HVAC units, Wi-Fi routers, water purifiers) with high-resolution PNG downloads.
- ⏱️ **Predictive SLA Countdowns:** Smart prioritization and countdown clocks for all open maintenance tickets.
- 📊 **Predictive Health Analytics:** Track equipment failure probability, recurring complaint hot-spots, and room repair histories.
- 📬 **Live Notification Hub:** Receive dynamic alert signals on resolution updates or pending inspections.
